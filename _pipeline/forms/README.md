# 五种产品形态规格

> 本文件是前端实现的**唯一依据**。每种形态定义一套完整的交互范式：
> 布局、导航、主交互、视觉语言、动效。**形态差异必须一眼可辨**，
> 不能靠换配色或换组件库冒充。

---

## 通用约束（所有形态共享）

- **技术**：React 18 + Vite 或 Vue 3 + Vite，按 config 的 `frontend` 字段
- **状态**：不引入 Redux/Pinia 之外的重量级方案；优先 Context / composable
- **路由**：react-router-dom 或 vue-router，路由守卫拦截未登录
- **请求**：统一封装 `api.js`，自动带 token、统一解包 `{code,data,message}`
- **登录态**：`localStorage` 的 `<prefix>_token` / `<prefix>_user`，prefix 由 config 决定
- **错误处理**：401 自动登出并跳登录；403 显示无权限页
- **必备页面状态**：加载态（骨架屏或 spinner）、空态（引导文案 + 行动按钮）、错误态（重试）
- **响应式**：≥1280 为主，≥768 可用，移动端不崩

## 1. `board` — 看板形态

**代表**：FlowBoard（敏捷协作）

| 维度 | 规格 |
| --- | --- |
| 布局 | 顶部工具栏 + 横向多列泳道，列可横向滚动 |
| 导航 | 顶栏项目切换器（下拉）+ 搜索 + 筛选 chips + 视图切换 |
| 主交互 | **拖拽卡片跨列**（HTML5 DnD 或 dnd-kit），松手即调 `PUT /issues/:id` 改 status |
| 卡片 | 标题、优先级色条、负责人头像、故事点、截止日期、标签 |
| 详情 | 点击卡片 → 右侧抽屉，含描述、评论流、编辑表单 |
| 动效 | 拖拽时卡片倾斜放大、落位弹性、列高亮 |
| 视觉 | 清爽工程风：浅灰底、白色卡片、细边框、优先级用左色条而非整块染色 |

**关键差异点**：状态流转靠**拖动**，不是下拉框。这是评委最容易记住的一点。

## 2. `map` — 地图空间形态

**代表**：CityLens（城市设施巡检）

| 维度 | 规格 |
| --- | --- |
| 布局 | **地图铺满全屏** + 左侧筛选面板（可收起）+ 右侧详情抽屉 |
| 导航 | 地图上的标记点即导航；顶部搜索定位 + 图层切换 |
| 主交互 | 点标记 → 侧滑详情；筛选改变标记显隐；定位到我的位置 |
| 地图 | Leaflet + 免费瓦片（OpenStreetMap）。**必须有离线降级**：瓦片加载失败时用纯色底 + 网格线，标记仍可用 |
| 标记 | 按状态着色（正常绿 / 待检黄 / 故障红），聚合显示数量 |
| 详情 | 设施信息、巡检历史时间线、上报故障表单 |
| 视觉 | 地图为主角，面板半透明浮层，圆角阴影，克制用色 |

**关键差异点**：**空间**是主界面。其它系统都是列表，它是一张地图。

## 3. `chat` — 对话流形态

**代表**：InterviewGo（AI 面试陪练）

| 维度 | 规格 |
| --- | --- |
| 布局 | 左侧会话列表（可收起）+ 右侧全屏对话区 |
| 导航 | 会话列表即导航；顶部当前会话标题 + 操作 |
| 主交互 | **流式输出**（逐字打字机）；消息内嵌卡片（评分、建议、题目） |
| 消息 | 用户右侧、AI 左侧、带头像；支持 Markdown；支持重新生成、复制 |
| 输入 | 底部输入框，支持 Enter 发送、Shift+Enter 换行、语音输入按钮 |
| 特色 | 会话结束生成**评分报告**，以卡片形式插入对话流 |
| 视觉 | 对话气泡、圆润、克制留白；AI 消息带淡淡背景色区分 |

**关键差异点**：**对话即产品**。没有列表页、没有表格，一切在对话里发生。

## 4. `editor` — 编辑器优先形态

**代表**：Inkwell（知识库写作）

| 维度 | 规格 |
| --- | --- |
| 布局 | 左侧文档树 + 中间编辑器主体 + 右侧大纲/属性面板 |
| 导航 | 文档树点击切换；顶部面包屑 |
| 主交互 | **所见即所得编辑**，输入即渲染；斜杠命令插入块 |
| 编辑器 | 优先 contenteditable 自研轻量富文本（标题/粗体/斜体/列表/引用/代码块/分割线），避免重依赖 |
| 自动保存 | 停止输入 1.5s 后自动保存，顶部显示"已保存 / 保存中" |
| 大纲 | 从正文提取标题生成，点击跳转 |
| AI | 选中文字 → 浮动工具条（润色/扩写/精简/总结） |
| 视觉 | 纸张质感，衬线正文、无衬线界面，大留白，专注模式（隐藏侧栏） |

**关键差异点**：**编辑器占据屏幕中心**，不是表单弹窗。

## 5. `timeline` — 时间轴形态

**代表**：Chronicle（个人成长档案）

| 维度 | 规格 |
| --- | --- |
| 布局 | 中轴纵向时间轴，左右交错卡片；顶部时间刻度导航 |
| 导航 | 按年月跳转；滚动时当前月份高亮 |
| 主交互 | 滚动回溯 + 点击事件展开详情；拖拽调整时间？否——保持只读叙事感 |
| 节点 | 按类型着色（里程碑/学习/项目/荣誉），带图标 |
| 详情 | 展开显示描述、附件、关联标签、影响 |
| 统计 | 顶部汇总：总条目、跨度、各类型占比（mini 条形） |
| 视觉 | 一条贯穿的中轴线 + 节点圆点；左右交错；滚动淡入动画 |

**关键差异点**：**时间是第一维度**。其它系统的列表按创建时间倒序，它按时间轴叙事展开。

## 形态与组件库的对应

| 形态 | 项目 | 组件库 | 前端 |
| --- | --- | --- | --- |
| board | FlowBoard | shadcn/ui + Tailwind | React |
| map | CityLens | Element Plus | Vue |
| chat | InterviewGo | MUI | React |
| editor | Inkwell | Arco Design | Vue |
| timeline | Chronicle | Chakra UI | React |

**注意**：形态决定交互，组件库决定观感。两者都要落地，不能只做其中一个。

## 实现检查清单（每个形态交付前自查）

- [ ] 布局范式与规格一致（不是"侧边栏 + 列表 + 弹窗"的通用模板）
- [ ] 主交互按规格实现（拖拽 / 地图点选 / 流式对话 / 所见即所得 / 时间轴）
- [ ] 加载态、空态、错误态齐全
- [ ] 登录/登出/403/404 完整
- [ ] 列表有分页或无限滚动
- [ ] 表单有前后端双重校验
- [ ] `npm run build` 零错误
- [ ] 与其它四套并排看，布局一眼不同
