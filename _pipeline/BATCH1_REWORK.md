# 前五套深化改造方案（第二批次）

> 目标：把第一批五套从「同一骨架换皮」深化为「五种不同产品形态」。
> 后端不动（已通过测试），只改前端形态层。

---

## 问题诊断

第一批做完组件库替换后，五个项目的**共性仍然过强**：

| 共性 | 出现在 |
| --- | --- |
| 左侧竖排侧边栏导航 | 全部五个 |
| 主区域是「列表 / 卡片网格」 | 全部五个 |
| 操作靠「弹窗表单」 | 全部五个 |
| Admin 仪表盘 = 统计卡 + ECharts | 全部五个 |
| 页面结构 = 登录页 + 若干功能页 + 后台页 | 全部五个 |

换掉的是皮（配色、圆角、组件外观），没换的是骨（布局范式、导航模型、主交互）。
评审同时打开两个，第二眼就能看出是同一套模具。

**深化方向**：让每个项目的**布局范式与主交互**都不同。

---

## 逐套改造方案

### 1. MindCare —— 沉浸式卡片流

**现状**：左侧边栏 + 各页面独立布局

**改造**：
- 取消左侧边栏，改为**底部悬浮胶囊导航**（移动优先的形态，居中悬浮）
- 首页改为**纵向滚动卡片流**：今日心情、最近测评、冥想推荐、陪护对话入口，卡片高度不一，滚动时视差淡入
- 冥想页改为**全屏沉浸模式**：进入后隐藏所有导航，只剩呼吸圆环 + 计时，ESC 退出
- 情绪日记改为**时间轴式卡片**（不是列表）
- 配色保持柔和紫，但布局从「后台」变成「App」

**记忆点**：唯一一个像手机 App 的，不是像后台管理系统。

---

### 2. ScholarBoard —— 编辑器优先 + 命令面板

**现状**：顶部导航 + 卡片网格列表

**改造**：
- 笔记页改为**三栏编辑器**：左侧笔记树 + 中间编辑器主体 + 右侧标签/属性
- 点击笔记直接在中间编辑，不是弹窗
- 引入 **⌘K 命令面板**：全局唤起，可搜索笔记、跳转页面、执行操作（新建笔记、新建任务、AI 润色）
- 简历页改为**分栏对比**：左侧原稿可编辑，右侧 AI 润色稿只读，中间「应用」按钮
- 任务页保留看板，但改为可拖拽（与 FlowBoard 区分：这里更简洁，无泳道装饰）

**记忆点**：唯一有命令面板的，键盘驱动。

---

### 3. EduPulse —— 可拖拽驾驶舱网格

**现状**：侧边栏 + 独立页面

**改造**：
- 首页改为**可拖拽的 Widget 网格**（类似 Grafana / 手机桌面）：每个统计卡、图表、待办都是可拖动重排的 widget
- 布局用 CSS Grid + 拖拽排序，位置存 localStorage
- 数字人教师**常驻右下角悬浮**，可点击展开为全屏对话（不是独立页面）
- 题库练习改为**卡片翻页式**（一题一屏，左右滑切），不是列表
- 配色保持赛博霓虹，但布局从「后台」变成「驾驶舱」

**记忆点**：唯一能拖拽重排首页的，仪表盘即桌面。

---

### 4. HiveMarket —— 集市网格 + 抽屉式详情

**现状**：顶部导航 + 卡片网格 + 独立详情页

**改造**：
- 首页改为**瀑布流集市**（小红书式不等高网格），滚动加载
- 商品详情改为**右侧抽屉**（不跳页），点击卡片即滑出，可连续浏览
- 发布改为**全屏向导**（分步：拍照 → 填信息 → AI 生成描述 → 预览 → 发布）
- 消息改为**浮层聊天窗**（右下角气泡，类似客服），不是独立页面
- 保留粗野主义的 3px 黑边与硬阴影，但布局从「电商后台」变成「逛集市」

**记忆点**：唯一用瀑布流 + 抽屉详情的，像逛街不像管货。

---

### 5. ExamPrep —— 保持终端，但强化命令行

**现状**：已经是终端形态，但交互仍是「点按钮切视图」

**改造**：
- 引入**真实命令行输入**：底部输入框可敲命令（`plan`、`quiz`、`stats`、`goal`、`ai`、`help`）
- 命令有自动补全提示
- 保留按钮导航作为「快捷方式」，但命令行是主交互
- 输出区支持**打字机效果**逐行输出
- 增加 `history` 命令显示历史指令

**记忆点**：唯一能用命令行操作的，真的像终端。

- [ ] 后端接口零改动
- [ ] localStorage key 零改动
- [ ] `npm run build` 零错误
- [ ] 与原版对比，布局一眼不同
- [ ] 与其它九套并排看，不重复
